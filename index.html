FMTOT · Golf-Ball Case Study

Knowledge-Guided Tracking of Fast-Moving Tiny Objects under Motion Blur

A three-stage, knowledge-guided pipeline that tracks a fast-moving, tiny golf ball through severe motion blur: motion-guided launch tracking, appearance-guided tiny-object localization, and selective least-squares trajectory recovery.

Overview

Tracking a driven golf ball is a hard instance of the fast-moving tiny-object problem: the target is only a few pixels wide, moves across most of the frame between exposures, and smears into a motion-blur streak. FMTOT decomposes the task into three cooperating stages, each guided by prior knowledge of how the ball behaves rather than by a single learned detector.

Method

A knowledge-guided handoff passes control from stage to stage using a Compactness Transition Score, so each module runs only where its assumptions hold.

Stage 1

Motion-guided launch tracking

Estimates the launch direction from a Motion History Image and multi-hypothesis search, then grows an initial trajectory. No assumption that the ball flies upward.

Stage 2

Appearance-guided tiny tracking

Normalized multi-cue candidate scoring for the few-pixel ball. Three texture descriptors are compared: LBP, LTP, and CSWC (the weighted variant in code).

Stage 3

Selective trajectory recovery

Least-squares fit of a linear-x / parabolic-y motion model over reliable observations, recovering the descending path where appearance tracking is unreliable.

Motion model fitted in Stage 3: x(t) = a₁t + a₀, y(t) = b₂t² + b₁t + b₀, using only reliable (MID_OK) Stage 2 points from the image-plane apex onward.

Dataset

The full dataset (Thesis_Data, ~5.6 GB zipped) holds the raw videos, per-frame images, ground-truth annotations.csv, and per-video results for 21 sequences. It is hosted on Google Drive because it exceeds GitHub's file-size limits.

Download: Thesis_Data.zip on Google Drive (~5.6 GB).
Contents: 01_data/ (videos + frames + annotations), 02_code/ (pipeline), 03_summary/ (result tables). The code and all result tables are also mirrored in this repository.

Code

The pipeline is plain Python + OpenCV + NumPy. Each video folder provides frames/ and annotations.csv.

fmtot/
├─ code/
│  ├─ run_pipeline.py          # end-to-end tracker (Stage 1 → 2 → 3)
│  ├─ stage1.py                # motion-guided launch + initial trajectory
│  ├─ stage2.py                # LBP / LTP / CSWC tiny-object tracking
│  ├─ stage3.py                # least-squares trajectory recovery
│  └─ stage3_offline_eval.py   # offline Stage 3 evaluation (reproduces Table V)
└─ summary/
   ├─ paper_summary/           # tables used in the paper
   └─ raw_summary/             # full consolidated results
# general tracking (run inside a video folder with frames/ + annotations.csv)
python run_pipeline.py

# offline Stage 3 experiment (reads existing Stage 2 outputs)
python stage3_offline_eval.py

In code, the method key weighted corresponds to CSWC in the paper.
